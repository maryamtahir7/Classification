# 🌸 AI Data Classification using Iris Dataset

A beginner-friendly Machine Learning project that demonstrates the complete workflow of building a classification model using the famous Iris dataset from Scikit-learn.

---

## 📌 Project Overview

This project covers the fundamental steps of supervised machine learning:

- Load and explore the dataset
- Preprocess the data
- Split data into training and testing sets
- Train a Decision Tree Classifier
- Evaluate model performance
- Predict new samples

---

## 🛠️ Technologies Used

- Python 3
- Pandas
- NumPy
- Scikit-learn

---

## 📂 Dataset

The project uses the built-in **Iris Dataset** from `sklearn.datasets`.

**Dataset Information:**
- 150 flower samples
- 4 input features
  - Sepal Length
  - Sepal Width
  - Petal Length
  - Petal Width
- 3 target classes
  - Setosa
  - Versicolor
  - Virginica

No external dataset download is required.

## 📊 Model Workflow

The script performs the following tasks:

1. Loads the Iris dataset.
2. Displays dataset information and statistics.
3. Splits the dataset into training and testing sets.
4. Trains a Decision Tree Classifier.
5. Evaluates the model using:
   - Accuracy Score
   - Classification Report
   - Confusion Matrix
6. Predicts the class of a new flower sample.
